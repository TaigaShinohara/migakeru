# ミガケル（Migakeru）

> 自分のこと、昨日より少し好きになる。

男磨きはモテるためではなく、鏡の自分に納得するため。今日やることは **3つだけ**。
できたら、それが自信になる。できなかった日は、持ち越さない。

## どんなアプリか

- **今日の3つ**：からだ／みため／こころから毎日1つずつ自動で選出。タップ1回で完了。差し替えは1日1回（ボタンに「何が何に変わるか」を明記）
- **卒業システム**：直近21日で5回できた習慣は「身についてきたみたい」と提案され、卒業バッチになる。責めない設計は文言ではなく仕組みで担保（未完了は翌日に持ち越さない）
- **鏡タイム**：週の積み重ねを「連続」ではなく「量」で見る。週を遡って過去の一言も読める
- **整え図鑑**：爪・肌・髪・姿勢など12テーマの小さな読み物
- **オンボーディング**：11ページ・1ページ1主張。質問1問の答えが選出に実際に反映され、試し操作は本物の「今日の1つ目」

権限ゼロ・アカウント登録なし・データは端末内のみ。

## 技術

- Kotlin + 素の Android View（Compose なし、依存は JUnit のみ）
- minSdk 26 / targetSdk 35
- 永続化は SharedPreferences
- 単体テスト 11 件（卒業条件の到達可能性を28日シミュレーションで検証するテストを含む）

## ビルド

Gradle 8.9 で：

```sh
gradle testDebugUnitTest assembleDebug
```

署名は任意です。`.local/signing.properties` と `.local/migakeru.keystore` があればそれを使い、無ければ通常のデバッグ署名でビルドされます（`.local/` は .gitignore 済みで、鍵はリポジトリに含まれません）。
