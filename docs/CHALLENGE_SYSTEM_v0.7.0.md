## 本人のルール（原文の骨子）

- 沢山ある「チャレンジ（やりたいこと）」から3つ選んで、自分の組み合わせを作り、それをこなしていく。
- チャレンジは内容ごとにポイントが振り分けられており、継続が難しいほどポイントがつく。
- 自分のチャレンジをすべて継続できていたら、新たなチャレンジをセットし、自分に課すことができる。
- セットされるチャレンジに応じてポイントは毎日付与される。
- できていないとマイナス1ポイント。引かれるのはチャレンジの内容に関係なく1ポイント。

## パソパソが決めた細部（本人の委任範囲）

- **カタログ**：従来の基本15＋予備9＝全24件を全て最初から選択可にした（柱の区分は表示のみ）。
- **ポイント表**：継続の難しさで1〜5点。筋トレ5／8000歩・スマホを置いて30分・決めたことをやり切る4／
  姿勢・靴の手入れ・寝る支度・瞑想3／他は1〜2。表の正本は `MigakeruLogic.POINTS`。
- **精算**：日付が変わった後の初回起動時に、前日までの未精算日をまとめて精算する。
  その日に有効だったセット（変更履歴から復元）について、完了＝+ポイント、未完了＝−1（内容によらず一律）。
  アプリを開かなかった日も同じルールで精算される（記録がない＝未完了）。
  v0.7.0導入より前の日は、新ルールが存在しなかった期間なので精算しない（導入日から）。
- **枠アンロック**：「全部継続できていたら」を「全チャレンジ完了の日が3日連続」と定義した。
  達成で枠+1（最大6）、連続記録はリセット。1つでも欠けた日は連続記録リセット。
  アンロック時は今日画面に祝福ボックスを出す。
- **組み合わせの変更**：いつでも変更可。変更はその日から有効（履歴に日付つきで残る）。
- **スコア**：合計ポイントは0未満にもなる（本人のルールどおり、下限なし）。
- **既存ユーザーの移行**：旧方式で当日出ていた3つを最初のセットとして引き継ぐ。スコアは0から。
  新規ユーザーはオンボーディング後にカタログで自分の3つを選ぶ。
- **残したもの**：バディの反応（枠アンロック間近の声かけを追加）、鏡タイム（日ごとの●○＋ポイント表示に変更）、
  図鑑、週一言。卒業バッチは「前の方式の記録」として わたし画面に残置（新規の卒業は発生しない）。

## v0.9.0 追記（2026-11-27）— 実機の崩れ修正＋チャレンジ倍増

本人の実機スクショで判明した崩れの修正と、チャレンジ倍増の指示で実施。

- **崩れの原因と修正**：カードの名前・一言に固定 dp 高さ（58／46）を使っていたが、文字は sp で端末の文字サイズ設定に追従して大きくなるため、大河の端末（大きめ設定）では2行目が半分だけ描かれる「文字欠け」になった。固定高さをやめ、最小高さ（minHeight）に変更——標準サイズでは今までどおり整い、大きい文字ではカードが伸びて欠けない。教訓：sp で描く文字に dp の固定高さを被せない。
- **チャレンジ 24→48件**：各柱+8件（EXTRA リストとして末尾に追加し、既存の並びと既存セットには影響なし）。追加分も全件に固有色（全48色すべて相異なる）・応援の一言・専用アイコン付き。新アイコン24種は一時テストでシート描画して全件目視確認済み（唇アイコンは初版が口ひげに見えたため描き直し）。
