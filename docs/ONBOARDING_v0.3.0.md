# ミガケル オンボーディング記録（v0.3.0 / 2026-11-19）

mobile_onboarding スキル（0.10.0）準拠で設計・実装。

## コンセプトの読み取り

- コンセプト：回復途上の男性が、朝アプリを開く場面で、今日の3つだけを受け取ることで、鏡の自分に少し納得できる体験
- 解決する困りごと：「何をすればいいか分からない／続かない／できなかった自分を責める」の3つ
- 最初の小さな成功：今日の1つ目をタップして完了させること
- 4条件の具体化：①何のためか＝「今日の3つだけを出すアプリ」と言い直せる ②スリーステップ＝開く／タップで完了／週1で鏡を見る ③ワクワク＝卒業バッチの山場を接続の直前に置く ④早く使いたい＝接続ページの先は今日画面そのもの、試し操作の完了は実記録になる

- 設計 §5.5 旧案との差：Q2（朝／夜）・Q3（写真）は「答えの使い道がない質問は入れない」原則により、通知・写真の実装時へ送った（設計 v0.5 に記録）

## チェック（出荷前）

- 1ページ1主張：全11ページで主張は1つずつ（数えて確認済み）
- スリーステップ：ちょうど3つ（開く／タップ／鏡）
- 質問と結果の分離：選択（p1）とマッチ（p2）は別ページ。反応と遷移の順番（反応→余韻→遷移→順番に入場）も分離実装
- インタラクション：選択＋試し操作の2回。「あとで試す」は完了扱い＋静かな一言、最初の成功は別状態（first_success）
- 保証表現なし（「ぴったり」は目的と使い方の話に限定）
- 完了時間の目安：読み物ページ各3〜5秒＋選択・試し操作で、合計60〜90秒想定
- 未確認：人間の体験確認（4条件の達成判定）は実機待ち行列。AIの動作確認だけで達成とは扱わない
