# 熱血バディ v0.4.0 実装記録

本人の指示（2026-11-22）：「画面右上に熱血キャラを置き、その左に吹き出しをつけてセリフを表示できるようにしたい。セリフは一旦挨拶文だけ。熱血キャラは顔だけ。人間ではない親しみやすい見た目で。動物はやめて」

## 実装

- **配置**：「今日」画面の最上部。右端にキャラの顔、その左に吹き出し（しっぽ付き）。日付行と「今日の3つ」見出しはその下に続く。
- **キャラ**：炎（ほのお）。人間でも動物でもない。「熱血」＝心の中の火、という男磨きのテーマにも一致する。顔だけを Canvas で描画（`BuddyView.kt` の `FlameFaceView`）。
  - 外炎：アプリの差し色オレンジ（#E65100 系）を一段明るくしたグラデーション。内炎：クリーム〜黄。
  - 表情：太い眉を中央へ寄せて「決意」、丸い目＋ハイライト、開いた笑口＋小さな舌、頬の照れ色で親しみやすさを担保。
  - 動き：下端を支点に ±3.5% のゆらぎ（約0.95秒周期）。炎の揺れとして意味のあるアニメーションのみ。画面を離れると停止。
- **吹き出し**：読み物ガラス（既存の card() と同素材）＋右向きのしっぽ（`BubbleTailView`）。文字は ink 色 15sp 太字。
- **セリフ**：挨拶のみ。時間帯で4種（`MigakeruLogic.greetingForHour`、境界テストあり）。
  - 5–10時「おはよう！今日も整えていこう！」
  - 11–16時「こんにちは！調子はどうだい？」
  - 17–22時「おつかれさま！今日もよくやってる！」
  - 23–4時「夜だな。無理せずいこう。おつかれさま！」
  - 熱血でも追い込まない——アプリのコンセプト（危機感で追い込む語り口は不採用）の範囲内で、勢いと労いを両立させた。
- **アクセシビリティ**：行全体に contentDescription「応援キャラの挨拶：…」を設定。

- セリフの拡張（完了時の一言、卒業提案への反応など）は本人の指示があった時だけ足す。今回は挨拶のみで止めた。
